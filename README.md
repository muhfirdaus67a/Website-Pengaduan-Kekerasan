## 🎯 Tentang Proyek

**Website Pengaduan Kekerasan Kabupaten Jember** adalah sistem informasi berbasis web yang dirancang untuk memberikan akses mudah dan aman bagi masyarakat dalam melaporkan tindak kekerasan. Sistem ini menghubungkan pelapor langsung dengan admin pengelola laporan secara digital, cepat, dan terstruktur.

Sistem ini hadir dengan **dua peran utama**:
- 👤 **Masyarakat (User)** — Membuat pengaduan, memantau status, dan memberikan ulasan
- 🛡️ **Admin** — Mengelola laporan masuk, mempublikasikan berita, dan mengekspor rekap pengaduan

## ⚙️ Instalasi

### Prasyarat

- XAMPP / Laragon (PHP + MySQL + Apache)
- Browser modern

### Langkah Instalasi

```bash
# 1. Clone repositori
git clone https://github.com/username/pengaduan-kekerasan-jember.git

# 2. Pindahkan folder ke htdocs (XAMPP) atau www (Laragon)
# Contoh XAMPP:
cp -r pengaduan-kekerasan-jember/ C:/xampp/htdocs/
```

### Konfigurasi Database

```bash
# 3. Buka phpMyAdmin di http://localhost/phpmyadmin
# 4. Buat database baru bernama: pengaduan_jember
# 5. Import file SQL dari folder database/
```

### Konfigurasi Koneksi

```php
// config/koneksi.php
$host     = "localhost";
$user     = "root";
$password = "";
$database = "pengaduan_jember";
```

```bash
# 6. Akses aplikasi di browser
http://localhost/pengaduan-kekerasan-jember
```

### Alur Pengaduan

```
Masyarakat mengisi form pengaduan
          ↓
Laporan tersimpan & masuk ke admin
          ↓
Admin meninjau kelengkapan laporan
          ↓
Admin menerima atau menolak laporan
          ↓
Masyarakat cek status & beri ulasan
```
